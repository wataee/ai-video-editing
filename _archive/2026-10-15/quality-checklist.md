# quality-checklist.md — Обязательный контроль качества готового видео

> **Фундаментальное правило:** Завершение команды рендеринга с кодом 0 **НЕ означает**, что видео проверено и готово к сдаче.  
> Проект считается выполненным только после прохождения сквозного контроля готового медиафайла.
> Если какой-то аспект невозможно проверить автономно, Claude обязан прямо написать об этом в отчёте, а не декларировать «всё проверено».

---

## 1. Градация критичности дефектов

- 🔴 **CRITICAL (Блокер):** Экспорт бракуется, сдача клиенту запрещена.
  *(Искажение смысла, рассинхрон речи и субтитров >0.3 с, клиппинг звука, обрезание лица спикера, закрытие текста интерфейсом, чёрные или зависшие кадры, нарушение авторских прав).*
- 🟡 **MAJOR (Существенный дефект):** Требует исправления, если нет прямого согласования от клиента.
  *(Слишком быстрая сменяемость текста, перепады тембра звука, спорный B-roll, висячие предлоги, музыка заглушает слова).*
- 🟢 **MINOR (Косметический дефект):** Исправляется по возможности или при повторном раунде правок.
  *(Небольшое отклонение оттенка плашки, мелкие нюансы пунктуации).*

## 2. Комплексный чеклист пострендерной проверки

### 1. Видеоряд и изображение
- [ ] 🔴 **CRITICAL:** Разрешение и соотношение сторон соответствуют ТЗ (по умолчанию ровно 1080×1920, 9:16).
- [ ] 🔴 **CRITICAL:** Отсутствуют непреднамеренные чёрные экраны (black frames) в начале, середине и на стыках сцен.
- [ ] 🔴 **CRITICAL:** Отсутствуют зависшие «мёртвые» кадры (freezed frames) при продолжающемся звуке.
- [ ] 🔴 **CRITICAL:** Кадрирование: голова и лицо спикера не обрезаются верхним или боковыми краями кадра при любых зумах.
- [ ] 🟡 **MAJOR:** Анимации воспроизводятся плавно, без рывков, пропусков кадров и задержек.
- [ ] 🟡 **MAJOR:** B-roll футажи не содержат визуальных ИИ-артефактов (шесть пальцев, искажённые черты лица, каша вместо текста).
- [ ] 🟡 **MAJOR:** Завершение ролика: последний кадр не висит неоправданно долго в тишине после окончания мысли спикера.

### 2. Субтитры и типографика
- [ ] 🔴 **CRITICAL:** Синхронизация: субтитры появляются точно в момент произнесения фразы (рассинхрон разрушает восприятие).
- [ ] 🔴 **CRITICAL:** Безопасные зоны: ни одна буква не залезает под системные кнопки TikTok/Reels/Shorts (справа) или описание (снизу).
- [ ] 🔴 **CRITICAL:** Защита лица: субтитры не перекрывают губы и подбородок спикера.
- [ ] 🔴 **CRITICAL:** Корректность текста: написание имён, терминов, брендов проверено по утверждённому глоссарию; грубые грамматические ошибки устранены.
- [ ] 🟡 **MAJOR:** Смысловые группы: фразы разбиты по естественным синтагмам, нет висячих предлогов («в», «с», «на») на концах строк.
- [ ] 🟡 **MAJOR:** Читаемость и хронометраж: длина показа строки достаточна для комфортного прочтения при среднем темпе взгляда.
- [ ] 🟡 **MAJOR:** Подсветка слов или анимация текста не спорит со смыслом речи и не вызывает зрительного переутомления.

### 3. Звуковой тракт и акустический баланс
- [ ] 🔴 **CRITICAL:** Аудиодорожка присутствует, звук распределён по обоим стереоканалам (нет звука только в левом ухе).
- [ ] 🔴 **CRITICAL:** Полное отсутствие цифрового клиппинга (перегруза) и хрипов: True Peak не превышает `-1.0 dBTP`.
- [ ] 🔴 **CRITICAL:** Интегральная громкость соответствует стандарту площадок (около `-14 LUFS`, допустимый коридор от `-13.5` до `-15.0 LUFS`).
- [ ] 🔴 **CRITICAL:** На стыках склеек нет щелчков, зажеванных согласных или резких обрывов речи.
- [ ] 🟡 **MAJOR:** Разборчивость речи в общем миксе: голос чётко доминирует над фоновой музыкой во всех частях ролика (музыка приглушена на 15–20 дБ).
- [ ] 🟡 **MAJOR:** Шумоподавление не исказило естественный тембр голоса (нет эффекта фазового «бульканья» или банки).
- [ ] 🟢 **MINOR:** Музыка и фоновый шум плавно затухают (fade out) в финале видео.

### 4. Редакторская драматургия и смысл
- [ ] 🔴 **CRITICAL:** Смысл спикера не искажён склейками, нет вырванных из контекста фраз, меняющих посыл на противоположный.
- [ ] 🔴 **CRITICAL:** Хук первых трёх секунд полностью честен и раскрывается в теле ролика.
- [ ] 🔴 **CRITICAL:** Утверждения на чувствительные темы (медицина, финансы, законы) сверены с исходником и помечены тегом `[ПРОВЕРИТЬ]`.
- [ ] 🟡 **MAJOR:** Ролик оканчивается логически завершённой мыслью, а не обрывом предложения.

### 5. Лицензионная чистота и авторские права
- [ ] 🔴 **CRITICAL:** Все шрифты, музыкальные треки, звуковые эффекты и видеофутажи имеют подтверждённые лицензии; источники зафиксированы в `credits.md`.
- [ ] 🔴 **CRITICAL:** В кадре отсутствуют чужие товарные знаки или конфиденциальная информация клиента.

## 3. Скрипты автоматической инструментальной проверки (FFmpeg)

Автоматика служит для **обнаружения подозрительных зон**. Она не заменяет смысловой просмотр, но гарантированно находит скрытый технический брак.

### 1. Проверка структуры контейнера и кодеков:
```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate,codec_name,pix_fmt -show_entries format=duration,size,bit_rate -of json out/final_video.mp4
```

### 2. Детекция чёрных экранов (black frames):
```bash
ffmpeg -i out/final_video.mp4 -vf "blackdetect=d=0.08:pix_th=0.10" -an -f null - 2>&1 | grep -E "black_start|black_duration"
```
*(Если найдены совпадения — зафиксируй таймкод и проверь, не выпал ли футаж).*

### 3. Детекция замерзших кадров (freezed frames):
```bash
ffmpeg -i out/final_video.mp4 -vf "freezedetect=n=-60dB:d=0.8" -an -f null - 2>&1 | grep -E "freeze_start|freeze_duration"
```

### 4. Детекция провалов звука и нежелательной тишины:
```bash
ffmpeg -i out/final_video.mp4 -af "silencedetect=noise=-38dB:d=0.6" -f null - 2>&1 | grep -E "silence_start|silence_duration"
```

### 5. Точный замер уровней громкости (EBU R128):
```bash
ffmpeg -i out/final_video.mp4 -af "loudnorm=I=-14:TP=-1.0:LRA=11:print_format=json" -f null - 2>&1 | tail -n 25
```
*(Сверь полученные поля `input_i` и `input_tp`: громкость должна быть в районе -14 LUFS, пик не выше -1.0).*

## 4. Методология покадровой инспекции Claude

Помимо автоматических логов, Claude обязан сгенерировать и проанализировать кадры из **зон повышенного риска**:

```bash
# Экспорт критических кадров в папку аудита:
mkdir -p work/qa_inspection

# 1. Первый кадр хука (время 00:00:00.100)
ffmpeg -ss 00:00:00.100 -i out/final_video.mp4 -vframes 1 work/qa_inspection/01_hook.png -y

# 2. Момент самой длинной фразы субтитров
ffmpeg -ss [ТАЙМКОД_ДЛИННОЙ_СТРОКИ] -i out/final_video.mp4 -vframes 1 work/qa_inspection/02_max_subtitles.png -y

# 3. Точки склеек и начала/конца B-roll (на границах сцен)
ffmpeg -ss [ТАЙМКОД_СТЫКА] -i out/final_video.mp4 -vframes 1 work/qa_inspection/03_transition.png -y

# 4. Финальный кадр ролика
ffmpeg -sseof -0.2 -i out/final_video.mp4 -vframes 1 work/qa_inspection/04_outro.png -y
```

**Что Claude инспектирует на стоп-кадрах:**
- Не наезжает ли текст на лицо или глаза спикера?
- Не выходит ли плашка за боковые поля безопасности?
- Нет ли эффекта размытия или пикселизации при масштабировании?

## 5. Стандартизированный отчёт о контроле качества (QA Report)

Данный отчёт формируется после выполнения всех тестов и прикладывается к финальной сдаче:

```markdown
# Отчёт о контроле качества (QA Report)

**Проверяемый файл:** `out/final_video.mp4`  
**Хронометраж:** 00:00:42.150 | **FPS:** 30.0 CFR | **Разрешение:** 1080×1920

### 1. Результаты инструментальных тестов
- **Громкость:** Integrated: -14.2 LUFS | True Peak: -1.0 dBTP (Норма)
- **Чёрные кадры:** Не обнаружены
- **Замершие кадры:** Не обнаружены
- **Провалы звука:** Пауз длиннее 0.6 с не обнаружено

### 2. Покадровая проверка критических зон
- Хук (0.1 с): Лицо в фокусе, заголовок по центру безопасной зоны.
- Длинная строка субтитров (18.4 с): Отступы по краям > 140 px, лицо спикера не перекрыто.
- Переходы и B-roll: Стыки чистые, артефактов склейки нет.
- Финал: Видеоряд завершается синхронно с затуханием звука.

### 3. Выявленные замечания
- 🔴 **CRITICAL:** Нет
- 🟡 **MAJOR:** Нет
- 🟢 **MINOR:** На фразе «маркетинг» (22.1 с) оставлен короткий вздох спикера для сохранения естественности речи.

### 4. Что не удалось проверить автономно (для редактора-человека)
- Тонкий эмоциональный эффект тембра фоновой музыки на динамиках смартфона.
- Субъективное восприятие юмора в первой фразе спикера.

**ИТОГОВЫЙ ВЕРДИКТ:** ✅ ГОТОВО К СДАЧЕ КЛИЕНТУ
```
