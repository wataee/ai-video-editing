# After Effects MCP — Регламент монтажа и моушн-дизайна

> Подключаемый модуль для монтажа в Adobe After Effects через локальный `after-effects-mcp`.
> Загружается в контекст только при работе в режиме **AE Montage**.

---

## 1. Архитектура и связь с After Effects

1. **Сервер MCP:** `tools\after-effects-mcp` (Node.js/TypeScript). Зарегистрирован в `.mcp.json`.
2. **Папка обмена (IPC):** `work\.ae-mcp` (внутри ROOT). Здесь создаются файлы `cmd_*.jsx`, `res_*.json` и превью-кадры.
3. **Движок AE:** Скрипт `ae-mcp-engine.jsx` работает внутри After Effects 2026 (%APPDATA%\Adobe\After Effects\26.0\Scripts\).
4. **Статус подключения:** Для проверки доступности используется инструмент `ae_get_active_comp` или CLI-скрипт `tools\after-effects-mcp.bat health`. Если AE закрыт, операции возвращают ошибку таймаута (10 сек).

---

## 2. Безопасность и ограничения `ae_run_jsx`

В MCP-сервер встроен строгий guard. Выполнение кода блокируется, если в строке содержатся:
- Системные вызовы: `callSystem`, `system.`, `.execute`
- Удаление и запись файлов ОС: `.remove`, `Folder.startup`, `File.encode`
- Пути к файлам вне директории проекта `C:\Users\timur\Videos\AI-Video-Editing\`

### Обязательные правила написания ExtendScript:
1. **Группировка отмены (Undo Group):** Любой скрипт длиннее одной строки обязан оборачиваться в:
   ```javascript
   app.beginUndoGroup("Описание операции");
   try {
       // Ваш код
   } finally {
       app.endUndoGroup();
   }
   ```
   Это гарантирует, что пользователь может отменить сгенерированный блок одним нажатием `Ctrl+Z`.
2. **Никаких модальных окон:** Запрещено использовать `alert()`, `confirm()`, `prompt()` — они блокируют поток After Effects и вызывают deadlock MCP-сервера.
3. **Пакетная отправка:** Не вызывай MCP инструмент на каждое изменение свойства. Группируй создание композиции, импорт и настройку слоев в один логический JSX-скрипт через `ae_run_jsx`.

## 3. Стандарты композиций и слоев

### Форматы и тайминги
- **Shorts / Reels / TikTok (9:16):**
  - Разрешение: `1080 x 1920` px
  - Частота кадров: `30 fps` (или `60 fps` при аналогичном исходнике)
  - Пиксели: Square Pixels (1.0)
- **Горизонтальные ролики (16:9):**
  - Разрешение: `1920 x 1080` (или `3840 x 2160` при 4K исходнике)
  - Частота кадров: `30 fps`

### Безопасные зоны (Safe Zones для 1080x1920)
- **Сверху:** отступ не менее `220 px` (интерфейс поиска и переключения вкладок)
- **Снизу:** отступ не менее `380 px` (название аккаунта, звук, описание, CTA)
- **Справа:** отступ не менее `130 px` (лайки, комментарии, репосты)
- **Слева:** отступ не менее `50 px`
- **Центр внимания:** субтитры и ключевая графика размещаются в диапазоне `y = 900..1400 px`.

## 4. Паттерны сборки таймлайна в AE

### Создание композиции и добавление исходников
```javascript
app.beginUndoGroup("Assemble Short");
var comp = app.project.activeItem;
if (!comp || !(comp instanceof CompItem)) {
    comp = app.project.items.addComp("Short_01", 1080, 1920, 1.0, 30.0, 30.0);
}

// Импорт ассета
var io = new ImportOptions(File("C:/Users/timur/Videos/AI-Video-Editing/clients/example/raw/video.mp4"));
var footage = app.project.importFile(io);
var layer = comp.layers.add(footage);
layer.startTime = 0;
layer.inPoint = 12.5; // Секунда начала по edit_plan.json
layer.outPoint = 42.5; // Секунда конца
app.endUndoGroup();
```

### Добавление субтитров и плашек
- Используй `tools\slice_words_json.py` для получения точных таймкодов слов выбранного фрагмента.
- При создании текстовых слоев задавай шрифт из утвержденных (`Montserrat`, `Inter`, `Roboto`, `Arial`).
- Для подсветки ключевых слов создавай аниматоры текста (Text Animators: Fill Color / Scale) либо отдельные текстовые слои с маркерами входа/выхода.

## 5. Цикл контроля при монтаже в AE
1. После сборки сцены запроси тестовый кадр или сделай экспорт кадра (`ae_render_comp` или через `tools\qa.bat`).
2. Проверь наложение графики на безопасные зоны.
3. Перед финальным рендером убедись, что звук сведен и уровни не клипуют.
