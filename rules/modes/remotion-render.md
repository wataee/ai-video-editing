# Remotion — Регламент программного рендеринга и моушн-компонентов

> Подключаемый модуль для монтажа и анимаций на базе Remotion (React + TypeScript).
> Загружается в контекст только при работе в режиме **Remotion Render**.

---

## 1. Структура проектов Remotion

В рабочей среде настроены стартовые шаблоны:
- `projects\remotion-tiktok-starter`: Вертикальные ролики (1080x1920, 30fps), настроенные динамические субтитры `@remotion/captions`, безопасные зоны.
- `projects\remotion-blank-starter`: Чистый холст под кастомные анимации и инфографику.

---

## 2. Архитектурные правила Remotion

1. **Детерминированность кадра:** Рендерер опирается на `useCurrentFrame()` и `useVideoConfig()`. Запрещено использовать `Date.now()`, `Math.random()` (без сида) или асинхронные запросы во время рендеринга кадров.
2. **Параметризация через Props:** Все изменяемые тексты, пути к видео, цвета и таймкоды должны передаваться через `inputProps` (файл `props.json` или параметры CLI). Не хардкодь контент в React-компонентах.
3. **Безопасные зоны:** Субтитры и важная инфографика должны быть завернуты в контейнер безопасных зон:
   ```tsx
   // Верх 220px, низ 380px, бока 130px
   <div style={{
     position: 'absolute',
     top: 220,
     bottom: 380,
     left: 130,
     right: 130,
     pointerEvents: 'none'
   }}>
     {children}
   </div>
   ```
4. **Анимации:** Используй `spring()` и `interpolate()` из `remotion`. Избегай неконтролируемых CSS-переходов (`transition: all 0.3s`), так как они могут пропускать кадры при оффлайн-рендере.

---

## 3. Интеграция субтитров (@remotion/captions)

- Для генерации субтитров используй JSON формат, получаемый из `tools\transcribe.py` (или `tools\slice_words_json.py`):
  ```json
  [
    {
      "text": "Привет,",
      "startMs": 150,
      "endMs": 480,
      "timestampMs": 150,
      "confidence": 0.98
    }
  ]
  ```
- Разбивай длинные фразы на смысловые синтагмы по 2–4 слова.
- Никогда не оставляй висячие союзы и предлоги на конце строки.

---

## 4. Команды сборки и рендеринга

- **Предпросмотр в Studio:**
  ```powershell
  npm run dev --prefix projects\remotion-tiktok-starter
  ```
- **Рендеринг финального видео:**
  ```powershell
  npx remotion render projects\remotion-tiktok-starter TikTokVideo out/render.mp4 --props=work/props.json --concurrency=4
  ```
- **Проверка шрифтов:** Перед рендером убедись, что используемые шрифты установлены в системе или импортированы локально.
