# Remotion Blank Starter — Лаборатория видеокомпозиций

Данный проект основан на официальном пустом шаблоне Remotion и предназначен для свободных экспериментов с типографикой, графикой, переходами, инфографикой и интеграцией готовых шаблонов компонентов.

---

## 1. Назначение проекта

Проект изолирован от конвейера субтитров и используется для:
- Создания и тестирования анимаций заголовков, плашек и логотипов (`lower-third`, `title-card`).
- Отработки переходов и эффектов масштабирования/кадрирования (punch-in, push-in, transitions).
- Построения графиков, таймеров и инфографики (счётчики, шкалы прогресса, диаграммы).
- Композитинга горизонтального (16:9, 1920×1080) и вертикального (9:16, 1080×1920) контента.
- Тестирования компонентов из библиотеки `references/remotion-templates-rve/`.

---

## 2. Структура проекта

```text
remotion-blank-starter/
├── src/
│   ├── Composition.tsx     # Холст для сборки экспериментальных анимаций
│   ├── Root.tsx            # Регистрация композиций с параметрами ширины, высоты и fps
│   └── index.ts            # Точка входа Remotion
├── package.json
└── tsconfig.json
```

---

## 3. Быстрый запуск

### 1. Запуск интерактивной студии Remotion
```bash
npm run dev
```
Интерфейс откроется в браузере по адресу `http://localhost:3000`.

### 2. Рендеринг тестового кадра (Still)
```bash
npx remotion still MyComp out/frame.png
```

### 3. Рендеринг готового ролика
```bash
npx remotion render MyComp out/video.mp4 --crf=18
```

---

## 4. Как интегрировать шаблоны из `references/remotion-templates-rve`

В директории `AI-Video-Editing/references/remotion-templates-rve/templates/` собрана коллекция из 81 чистого React/Remotion-компонента без внешних тяжелых зависимостей.

Чтобы добавить любой компонент в проект:
1. Скопируйте нужный `.tsx` файл из `references/remotion-templates-rve/templates/` в папку `src/components/`.
2. Импортируйте компонент в `src/Composition.tsx` или зарегистрируйте как отдельную `<Composition />` в `src/Root.tsx`.
3. Все анимации в этих компонентах используют стандартные хуки Remotion (`interpolate`, `spring`, `useCurrentFrame`, `useVideoConfig`), поэтому они полностью совместимы с текущей версией.
