# Remotion TikTok / Reels / Shorts Starter (Русскоязычное руководство)

Данный проект основан на официальном шаблоне Remotion для создания вертикальных видео (9:16) с автоматической генерацией и анимацией пословных субтитров в стиле TikTok, Reels и YouTube Shorts.

---

## 1. Архитектура и возможности

- **Формат:** 1080×1920 (9:16), частота кадров по умолчанию 30 fps.
- **Встроенная транскрибация:** Интеграция с Whisper.cpp (`@remotion/install-whisper-cpp`) и скриптом `sub.mjs`.
- **Пословные субтитры:** Библиотека `@remotion/captions` разбивает речь на страницы (`createTikTokStyleCaptions`) и пословные токены (`tokens`).
- **Стилизация текста:** Шрифт `Montserrat` (поддерживает заглавные начертания, обводку `WebkitTextStroke: "20px black"`, акцентную подсветку активного слова).
- **Безопасные зоны:** По умолчанию нижний отступ субтитров настроен на `bottom: 350px`, что предотвращает перекрытие текстом описания и кнопок интерфейса мобильных приложений.

## 3. Быстрый старт: Пошаговая инструкция

### Шаг 1: Замена исходного видео
1. Поместите ваше вертикальное видео в папку `public/` (например, `public/my-video.mp4`).
2. В файле `src/Root.tsx` укажите имя нового видео в свойстве `defaultProps`:
   ```typescript
   defaultProps={{
     src: "my-video.mp4",
   }}
   ```

### Шаг 2: Автоматическое создание субтитров
Для запуска транскрибации через встроенный Whisper.cpp выполните:
```bash
npm run create-subtitles
```
Скрипт автоматически:
- Извлечёт аудиодорожку в формате WAV 16 кГц во временную папку `temp/`.
- Выполнит транскрибацию с пословными таймкодами.
- Сохранит результат в файл `public/my-video.json`.

*(Примечание: Настройки модели и языка транскрибации находятся в файле `whisper-config.mjs`. По умолчанию используется английский язык `WHISPER_LANG = "en"`. Для русского языка измените на `"ru"`, а модель на `"small"` или `"base"`).*

Также для транскрибации можно использовать высокоскоростной локальный скрипт `faster-whisper`, настроенный в окружении `AI-Video-Editing/tools/venv-whisper`.

### Шаг 3: Запуск интерактивного предпросмотра (Studio)
```bash
npm run dev
```
Откроется веб-интерфейс Remotion Studio по адресу `http://localhost:3000`. Вы сможете покадрово просматривать ролик, проверять синхронизацию субтитров и на лету редактировать код.

## 4. Настройка стилей субтитров

Все ключевые визуальные параметры вынесены в компонент `src/CaptionedVideo/Page.tsx`:

- **Цвет подсветки активного слова:**
  ```typescript
  const HIGHLIGHT_COLOR = "#39E508"; // Ярко-зелёный (можно заменить на цвет бренда)
  ```
- **Размер шрифта:**
  ```typescript
  const DESIRED_FONT_SIZE = 120; // Максимальный размер (fitText автоматически уменьшит для длинных строк)
  ```
- **Положение по вертикали (безопасная зона):**
  ```typescript
  const container: React.CSSProperties = {
    bottom: 350, // Высота над нижним краем кадра в пикселях
    height: 150,
  };
  ```
- **Скорость смены строк (в миллисекундах):**
  В файле `src/CaptionedVideo/index.tsx`:
  ```typescript
  // 1200-1500 мс — показывать фразы из 3-5 слов
  // 300-500 мс — динамичный показ по 1-2 слова
  const SWITCH_CAPTIONS_EVERY_MS = 1200;
  ```

## 5. Экспорт и рендеринг итогового видео

Рендеринг финального MP4 выполняется через команду CLI:

```bash
npx remotion render CaptionedVideo out/tiktok_final.mp4
```

Для кодирования с повышенным качеством и параметром CRF 18:
```bash
npx remotion render CaptionedVideo out/tiktok_final.mp4 --crf=18
```
