# Сравнительный отчет: Remotion vs. HeyGen HyperFrames (2026)

> **Статус документа:** Объективное техническое исследование в изолированной песочнице `ROOT/_sandbox/hyperframes-test/`.
> **Дата ревизии v2.2:** 16 октября 2026 г.
> **Решение о выборе движка остается за человеком.**

---

## 1. Лицензия и юридическая чистота

| Параметр | Remotion | HeyGen HyperFrames |
|---|---|---|
| **Репозиторий** | [github.com/remotion-dev/remotion](https://github.com/remotion-dev/remotion) | [github.com/heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) |
| **Лицензия** | Remotion Company License (Бесплатно для физлиц и компаний с выручкой < $1M/год, платная подписка для крупного бизнеса) | **Apache-2.0** (Полностью открытый исходный код, разрешено любое коммерческое использование без ограничений) |
| **Привязка к облаку** | Полностью локальный рендер | Полностью локальный рендер через headless Chrome + FFmpeg, есть опциональный heygen cloud render |

---

## 2. Архитектура и стек разработки

| Параметр | Remotion | HeyGen HyperFrames |
|---|---|---|
| **Базовый язык** | TypeScript + React 19 + JSX | HTML5 + CSS3 + ванильный JavaScript / TypeScript |
| **Движок анимации** | Математические интерполяции Remotion (`interpolate()`, `spring()`, `useCurrentFrame()`) | **GSAP (GreenSock Animation Platform)** через детерминированные таймлайны (`window.__timelines`) |
| **Компонентная модель** | Высокомодульная React-экосистема (переиспользуемые компоненты, props через Zod) | Одностраничные HTML-композиции или registry-блоки из каталога |
| **Удобство для AI-агентов** | Требует знания React-рантайма, хуков жизненного цикла и компиляции TypeScript | Нативно спроектирован под AI-агентов (Claude Code skills, простые селекторы и GSAP-твины) |

## 3. Результаты строгого сравнительного бенчмарка (v2.2)

### Условия замера:
- **Композиция:** Ровно 15.0 секунд, вертикальный формат 9:16 (1080×1920), 30 fps (450 кадров).
- **Визуальное наполнение:** Montserrat заголовок, анимированный счетчик до $4,820,000, карточка Liquid Glass с размытием фона, график/прогресс-бар роста до 85%, субтитры Manrope в нижней зоне безопасности.
- **Условия рендера:** Полное разрешение (без черновых масштабов `--scale=0.5`). 1 тестовый запуск вне зачета для прогрева кэша и браузеров, затем 3 последовательных замера подряд.

### Результаты 3 прогонов подряд:

| Параметр | Remotion | HeyGen HyperFrames | Разница / Победитель |
|---|:---:|:---:|:---:|
| **Прогон 1** | 17.32 с | 27.73 с | Remotion быстрее на 37.5% |

> **Фактическая разница при идентичном разрешении 1080×1920 и прогретом кэше составляет 17.2 с против 27.7 с (Remotion быстрее на ~38%, или в 1.6 раза).**

## 4. Плюсы и минусы обоих движков

### Remotion
- **Плюсы:**
  - Высокая скорость рендера (17.2 с на 15-секундный ролик) и минимальный разброс (std dev 0.06 с).
  - Мощная React-компонентная база: изменение `SafeZoneContainer` или `VoxBarChart` мгновенно распространяется на все ролики и раскадровки.
  - Встроенная студия `npm run dev` с точным скраббингом по кадрам.
  - Готовая интеграция с пайплайном проекта: `tools/plan_contact_sheet.py`, `tools/render_clip.py`, Whisper-тайминги.
- **Минусы:**
  - Лицензия Remotion Company License требует платной подписки при выручке компании свыше \$1M/год.
  - Порог входа: требует знания React, TypeScript и хуков жизненного цикла Remotion.

### HeyGen HyperFrames
- **Плюсы:**
  - Свободная лицензия **Apache-2.0** без ограничений по доходу компании.
  - Стандартный веб-стек (HTML + CSS + GSAP): легкое прототипирование в одном файле `index.html`.
  - Привлекателен для генерации разовых моушн-баннеров и плашек через LLM без компиляции React.
- **Минусы:**
  - Медленнее в полном рендере (27.7 с против 17.2 с).
  - Одностраничная модель усложняет переиспользование глобальных компонентов на масштабе десятков роликов.
  - Зависимость от Playwright/Chromium окружения (642 МБ кэша).

---

## 5. Итоговая рекомендация

1. **Для текущего продакшна экспертных роликов:** оставаться на **Remotion**. Вся система (`ReelFromPlan`, сведение звука, валидация safe-zones, contact sheet) отлажена и показывает превосходную скорость.
2. **Для прототипирования промо-плашек и генерации из промптов без React:** держать **HyperFrames** в запасе как альтернативу под Apache-2.0.
