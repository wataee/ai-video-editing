# 01. Hooks & Script Architecture

## 1. Core Editorial Rule: 1 Video = 1 Core Idea
- Never combine multiple unrelated topics or ramble across concepts.
- Every video must have a single thesis statement delivered within the first 3 seconds.
- Every sub-point, b-roll clip, graphic, or caption must directly support the core thesis.
- If a sentence does not advance the single thesis or deliver emotional punch, cut it mercilessly.

## 2. Hook Library & Outlier Opening Patterns
The first 3 seconds decide whether the viewer stays or swipes. Use one of these proven hook patterns:

### Pattern A: Pattern Interrupt / Negative Frame
- Start in media res with an unexpected negative reality or counter-intuitive warning.
- *Visual*: Immediate camera punch-in (scale 1.0 -> 1.08) paired with heavy bass drop or low hit.
- *Script Template*: "Stop doing [Common Practice] if you want [Desired Outcome]." or "Almost everyone is completely wrong about [Topic]."

### Pattern B: Bold Visual Claim / Visual Anomaly
- Immediate high-contrast visual asset on screen within 0.1s of video start.
- *Visual*: Liquid glass card or 3D cutout popping into screen (`spring({ damping: 12, stiffness: 100 })`) with high-frequency whoosh.
- *Script Template*: "This single chart explains why [Entity] lost [Huge Number]."

### Pattern C: High-Contrast Statistic
- Concrete number ticking up rapidly on screen from 0 to target value with acoustic click/tick SFX.
- *Visual*: Giant monospace or bold geometric numbers growing inside safe zones.
- *Script Template*: "87% of creators fail before their 10th video because of this one mistake."

### Pattern D: The Screen Grab Reality
- Authentic UI card or mobile screenshot sliding in with paper slide or digital click sound.
- *Script Template*: "Look at this email I received yesterday."

## 3. Fact-Checking & Verification Protocol
- Every metric, date, historical claim, or statistical percentage must be verified against provided raw sources.
- If a claim or number cannot be verified with 100% confidence from the input data, **cut the line** or flag it immediately.
- Never allow hallucinated stats or vague "experts say" without specific attribution.
