# 16. Стилистическая связность и защита от «Солянки» (Anti-Mishmash Protocol)

> **КРИТИЧЕСКОЕ ПРАВИЛО ДЛЯ CLAUDE:**  
> Визуальная «солянка» (смешивание несовместимых стилей, шрифтов, анимаций и текстур в одном 60-секундном ролике) — главная причина отказов клиентов на Upwork и ощущения «дешевого AI-монтажа».  
> Любой проект обязан строго следовать **Принципу Стилистического Карантина (Rule of One)**.

---

## 1. Принцип Стилистического Карантина (Rule of One)

При получении любого клиентского брифа (`client_brief.md` или промпта):

1. **Ровно 1 Архетип / Пресет на проект:**  
   Ролик блокируется в одном конкретном дизайн-пресете (например, `SYS-01: Ali Minimal`, `SYS-03: Vox Editorial`, `SYS-04: Gadzhi Luxury` или `SYS-05: Cyber Tech`).
2. **Строгий запрет на кросс-контаминацию:**
   - **ЗАПРЕЩЕНО** вставлять рваную бумагу (`07_mixed_media`) в корпоративный минимализм (`01_business_minimal`).
   - **ЗАПРЕЩЕНО** ставить неоновый кибер-HUD (`05_cyber_tech`) или глиф-сетки в роскошный нуар (`04_luxury_dark_aesthetic`).
   - **ЗАПРЕЩЕНО** использовать прыгающие разноцветные эмодзи Хормози (`02_kinetic_viral`) в документальных расследованиях (`03_vox_documentary`).
3. **Правило триады цветов (Color Triad Lock):**
   - Ровно **3 цвета** на весь ролик:
     1. `Color_Background` (основа: глубокий темный или теплый светлый).
     2. `Color_Surface` (цвет подложек карточек с прозрачностью 80–90%).
     3. `Color_Accent` (акцентный цвет для ключевых слов, графиков и стрелок).
   - Никаких случайных цветов для отдельных плашек.
4. **Правило типографической пары:**
   - Ровно **2 начертания одного семейства** (или проверенная пара из `08-typography-pairings.md`):
     - Заголовок: `Header_Font` (Bold / Black / Display).
     - Текст / Субтитры: `Body_Font` (Medium / Regular).
5. **Единый профиль физики Remotion Spring:**
   - Все переходы и плашки в рамках одного видео используют **одну и ту же формулу пружины**:
     - *Smooth Tech / Corporate:* `{ damping: 20, stiffness: 90, mass: 0.8 }`
     - *Viral High Retention:* `{ damping: 14, stiffness: 180, mass: 0.6 }`
     - *Cinematic / Luxury:* `{ damping: 28, stiffness: 70, mass: 1.1 }`

## 2. 5-Фазовая анатомия вертикального видео (Scene Grammar)

Каждый ролик делится на 5 функциональных временных слотов. Референсы из папки `references/pinterest/` применяются строго по ролям:

```
[0.0s - 3.0s]        [3.0s - 18.0s]        [18.0s - 38.0s]       [38.0s - 52.0s]       [52.0s - 60.0s]
┌──────────────┐     ┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ BEAT 01:     │ ──> │ BEAT 02:     │ ───> │ BEAT 03:     │ ───> │ BEAT 04:     │ ───> │ BEAT 05:     │
│ HOOK HERO    │     │ CORE RHYTHM  │      │ PROOF CALLOUT│      │ CLIMAX PUNCH │      │ CTA & LOOP   │
└──────────────┘     └──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘
  Паттерн-хук           Говорящая голова      Факты, цифры,         Смысловой пик,         Бесшовный стык
  Контраст              Чистый сабтайтл       DeviceMockup          Сводная карта          с началом
```

### Beat 01: The Hook Hero (0.0s – 3.0s)
- **Цель:** Остановить свайп в первые 1.5 секунды.
- **Визуальная роль (`ROLE_HOOK_HERO`):**
  - Крупный акцентный заголовок (не более 3–4 слов), либо визуальный хук (пуш-ин камеры `1.0 -> 1.08`, появление главного артефакта, маскированный вырез спикера).
  - Никакой мелкой верстки, графиков и перегруза. Только 1 центральный объект внимания.
- **Звук:** 1 акцентный панч (глубокий bass drop или быстрый whoosh hit).

### Beat 02: Core Narrative Rhythm (3.0s – 18.0s)
- **Цель:** Вовлечь зрителя в суть истории, создать удобный темп восприятия.
- **Визуальная роль (`ROLE_SUBTITLE_ENGINE`):**
  - Спикер в фокусе (микро-дрифт камеры `1.0 -> 1.03`).
  - Чистые кинетические субтитры строго в нижней трети (`safe zone y: 1120..1380`).
  - Выделение цветом `Color_Accent` только **1 смыслового слова** на фразу (никакой радуги).
- **Звук:** Только голос спикера + фоновая музыка (`-22 dB` ducking). Без лишних звуков.

### Beat 03: Visual Evidence & Proof Callout (18.0s – 38.0s)
- **Цель:** Доказать авторитетность и пользу, удержать внимание зрителя («мясо» ролика).
- **Визуальная роль (`ROLE_CALLOUT_UI` / `ROLE_DEVICE_MOCKUP` / `ROLE_SPLIT_SCREEN`):**
  - На словах спикера о цифрах, софте, результатах или кейсе появляется ровно **1 UI-карточка**:
    - `01_business_minimal`: плашка с метрикой (`+142% Growth`) или сплит-сравнение.
    - `05_cyber_tech`: окно терминала, подсветка строки кода, 2.5D макет приложения.
    - `03_vox_documentary`: вырезка из газеты / документа с желтым маркером или карта.
    - `08_product_3d`: чистый макет смартфона с интерфейсом.
- **Звук:** 1 деликатный клик или тихий механический щелчок на появление карточки.

### Beat 04: Pacing Climax & Density (38.0s – 52.0s)
- **Цель:** Максимальная плотность инсайта перед развязкой.
- **Визуальная роль (`ROLE_PUNCH_ACCEL`):**
  - Сжатые тезисы (чеклист из 3 пунктов, быстрый монтажный ритм 1.5–2 секунды на кадр).
  - Смена ракурса камеры спикера (jump cut с кропом 1.15x).

### Beat 05: The Loop & CTA (52.0s – 60.0s)
- **Цель:** Зациклить просмотр (infinite retention loop) или побудить к целевому действию.
- **Визуальная роль (`ROLE_LOOP_CTA`):**
  - Финальная фраза строится так, чтобы грамматически продолжать первую фразу хука.
  - Аккуратная плашка с призывом (Save this / Link in bio / Comment "AI") без закрытия лица спикера.

## 3. Таблица функциональных ролей референсов (Reference Role Taxonomy)

Каждое изображение в каталоге `references/pinterest/` классифицируется по роли в таймлайне:

| Роль (Role Tag) | Назначение в таймлайне | Где используется в коде Remotion |
|---|---|---|
| `ROLE_HOOK_HERO` | Первый кадр (0–3 сек), захват внимания | Заглавная плашка, вырезка силуэта, титр |
| `ROLE_CALLOUT_UI` | Демонстрация данных, метрик, процентов | Компонент `<CalloutCard />`, плашки со стрелками |
| `ROLE_DEVICE_MOCKUP` | Демонстрация экрана смартфона/веб-сайта | Компонент `<DeviceMockup />` |
| `ROLE_SPLIT_SCREEN` | Сравнение "До / После" или "Спикер / Экран" | Компонент `<SplitScreen />` |
| `ROLE_SUBTITLE_ENGINE` | Оформление субтитров и подсветка слов | Компонент `<KineticCaption />` |
| `ROLE_DOCUMENT_PROOF` | Подтверждение фактов (статья, твит, отчет) | Компонент вырезки документа с хайлайтером |
| `ROLE_TRANSITION_SEAM` | Бесшовный переход между планами | Вспышка, глич, световой блик, вырезка |

## 4. Контрольный чеклист Claude перед сдачей плана монтажа (Anti-Mishmash QA)

Перед генерацией `beat_sheet.json` и рендером сцен в Remotion, Claude обязан проверить соответствие:

- [ ] **1. Задан ли один четкий Style Preset?** (Например: `01_business_minimal`).
- [ ] **2. Все ли цвета соответствуют палитре пресета?** (Не более 3 цветов на видео).
- [ ] **3. Все ли шрифты из разрешенного списка пресета?** (Локальные шрифты из `assets/02_FONTS/`).
- [ ] **4. Исключена ли кросс-контаминация?** (Нет ли элементов из других несовместимых категорий).
- [ ] **5. Распределены ли референсы по 5 фазам таймлайна?** (Хук -> Ритм -> Пруф -> Пик -> Луп).
- [ ] **6. Соответствует ли физика spring общему темпу?** (Одинаковый `damping` и `stiffness` для карточек).
- [ ] **7. Соблюдены ли Safe Zones?** (Верх: 220px, Низ: 380px, Бока: 100/130px).
