# Style Bible: Единый стиль экспертного вертикального ролика (9:16)

> **Статус документа:** Официальный дизайн-стандарт проекта  
> **Инженерия токенов:** Все числовые и цветовые параметры зафиксированы в коде `src/config/stylePresets.ts`. Переключение стиля не требует переписывания компонентов.

---

## 1. Кандидат A (ПО УМОЛЧАНИЮ): «Editorial Authority» (Редакционный авторитет)

### 1.1. Словесное описание (5 строк)
1. Премиальный кинематографический стиль высокобюджетных аналитических изданий (Vox, Apple Keynote).
2. Глубокий темный фон без визуального шума с акцентом на фактуру реальных документов и графиков.
3. Контрастная шрифтовая пара с идеальной читаемостью кириллических глифов и чистой геометрией.
4. Полупрозрачные подложки с эффектом матового стекла (Liquid Glass), не закрывающие спикера.
5. Спокойная, уверенная хореография движения с плавным нарастанием и пружинным затуханием без глитчей.

### 1.2. Цветовая палитра (3 основных цвета)
- **Primary (Фон):** `#09090B` (Глубокий темный цинк)
- **Secondary (Текст):** `#F4F4F5` (Чистый молочно-белый)
- **Accent (Фокусные метрики / акцент):** `#FFD60A` (Канареечно-желтый / теплая амбра)
- *Вспомогательный статус-цвет:* `#30D158` (Зеленый подтверждения)

### 1.3. Шрифтовая пара (из `assets/fonts/`)
- **Заголовок / Хук:** `Montserrat` (ExtraBold / Black, 800/900)
- **Субтитры / Текст карточек:** `Manrope` (Bold / SemiBold, 600/700)
- **Второй рукописный слой:** `Caveat` (для стрелок и ремарок)

### 1.4. Правила субтитров
- Смысловые кластеры строго по **2–3 слова**.
- Вертикальная позиция: `y: 1220 px` (SafeZone диапазон `y: 1120..1380 px`).
- Активное слово подсвечивается `#FFD60A`, остальные слова — `#F4F4F5`.
- Мягкая затемненная подложка `rgba(9, 9, 11, 0.85)` с блюром 16px.
- Время удержания блока: `max(0.8s, 0.3s * words)`.

### 1.5. Правила зума камеры
- Наезд (push-in): масштаб строго **1.0 ➔ 1.07** (+7%).
- Длительность: 14 кадров с плавным затуханием `power2.out`.
- Привязка строго к ударному слову смыслового бита.
- Зум камеры всегда выполняется **БЕЗ ЗВУКА** (0 SFX).

### 1.6. Правила звукового дизайна
- Удары и нарастания (Hits / Risers): `−14 dB` относительно измеренного RMS речи.
- Текстуры, щелчки, шорох бумаги: `−16 dB`.
- Свисты движения графики: `−20 dB`.
- Фоновая музыка: `−24 dB` с автоматическим сайдчейном (ducking) под голос.
- Плотность: не более 4–5 SFX на 30 секунд.

## 2. Кандидат B: «Nordic Minimalist» (Скандинавский минимализм)

### 2.1. Словесное описание (5 строк)
1. Аскетичный академический минимализм с фокусом на вес каждого произнесенного слова (Dan Koe, Черниговская).
2. Абсолютно чистый черный фон без градиентов, дающий максимальный контраст тексту в ленте.
3. Использование спокойного гротеска Inter с акцентом на типографику швейцарского плаката.
4. Полный отказ от цветных рамок, ярких подложек и декоративных моушн-эффектов.
5. Размеренный темп с глубокими драматическими паузами тишины после ключевых тезисов.

### 2.2. Цветовая палитра
- **Primary (Фон):** `#000000` (Глубокий черный OLED)
- **Secondary (Текст):** `#FFFFFF` (Снежно-белый)
- **Accent (Акцент):** `#30D158` (Мятно-зеленый статус)

### 2.3. Шрифтовая пара
- **Заголовок:** `Inter` (Bold, 700)
- **Субтитры:** `Inter` (Medium, 500)
- **Сноски:** `Caveat` (при необходимости)

### 2.4. Правила субтитров
- Блоки по **3–4 слова** целиком строкой.
- Позиция `y: 1280 px`.
- Без пословной анимации цвета: текст появляется целиком строкой и держится 1.5–2.5 секунды.

### 2.5. Правила зума камеры
- Камера практически статична (допустим медленный наезд 1.0 -> 1.04 за 6 секунд).
- Зум строго без звука.

### 2.6. Правила звука
- Музыка отсутствует либо тихий фоновый дрон на уровне `-28 dB`.
- SFX: 0–1 звук на ролик (только глухой саб-дроп на хуке).

## 3. Выбор активного стиля
По умолчанию в проекте активирован **Кандидат A («Editorial Authority»)** в файле `src/config/stylePresets.ts`:
```typescript
export const ACTIVE_STYLE: StyleTokens = STYLE_PRESETS["editorial-authority"];
```
Для переключения на Кандидата B достаточно изменить ключ на `"nordic-minimalist"`.
