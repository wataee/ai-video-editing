# Фоновая музыка (Background Music Assets)

> [!IMPORTANT]
> **Лицензионная политика:** В клиентских и коммерческих проектах разрешено использовать **исключительно** музыку с явным разрешением на коммерческое использование (Royalty-Free Commercial, CC0, YouTube Audio Library / Creator Music, Epidemic Sound / Artlist с подтверждённой подпиской).
> **Запрещено:** Скачивать музыку из непроверенных источников или использовать треки «no copyright» без сохранённой лицензии.

## Правила добавления треков:
1. Для каждого добавленного аудиофайла **обязательно** заполнить строку в таблице учёта ниже.
2. Сохранить текстовую копию условий использования или скриншот лицензии в папку `assets/music/licenses/<название_трека>/`.
3. Указать ограничения платформы (например, требуется ли указание авторства в описании).
