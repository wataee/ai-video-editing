# Звуковые эффекты (SFX Assets)

> [!IMPORTANT]
> **Лицензионная политика:** Разрешено использовать только звуковые эффекты (whoosh, pop, click, transition, risers, hits), распространяемые по лицензиям CC0 (Public Domain), коммерческим библиотекам с подтверждённой лицензией или с открытых площадок (например, freesound.org под лицензией CC0).

## Правила добавления SFX:
1. Заполнить строку в таблице учёта ниже для каждого звукового эффекта или пакета.
2. Сохранять подтверждение лицензии (копию страницы или текстовый файл) в `assets/sfx/licenses/`.
3. Не использовать звуковые эффекты, извлечённые из коммерческих фильмов, игр или чужих роликов без разрешения правообладателя.
