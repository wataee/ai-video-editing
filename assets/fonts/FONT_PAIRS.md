# Регламент шрифтовых пар рабочей станции

> **Жёсткое правило:** В одном видеоролике разрешено использовать **НЕ БОЛЕЕ ДВУХ шрифтов** из локальной папки `assets/fonts/`.  
> Любое использование третьего шрифта или системных шрифтов без согласования в брифе расценивается как брак.

---

## Проверенные шрифтовые пары (Google Fonts, полная поддержка кириллицы)

| Стиль ролика | Заголовок / Хук (Header) | Субтитры / Текст (Body) | Характер восприятия |
|---|---|---|---|
| **1. Tech / IT / Бизнес** | `Unbounded` (Bold / Black) | `Inter` (Medium / SemiBold) | Современный, технологичный, авторитетный |
| **2. Экспертный минимализм** | `Montserrat` (ExtraBold) | `Manrope` (Medium) | Чистый, премиальный, легко читается |
| **3. Маркетинг / Динамика** | `Rubik` (Black) | `Onest` (SemiBold) | Энергичный, плотный, дружелюбный |
| **4. Документальный / Кейсы** | `Oswald` (Bold) | `Inter` (Regular / Medium) | Строгий, журналистский, фактологический |

---

## Правила типографики:
1. **Регистр:**
   - Заголовок хука: допускается `ALL CAPS` (с увеличенным кернингом letter-spacing +2..+4%).
   - Основные субтитры: **строчные буквы с заглавной** (Sentence case). Сплошной ALL CAPS в длинных субтитрах утомляет зрение.
2. **Контрастность:**
   - Основной цвет: `#FFFFFF` (или чистый офф-вайт `#F4F4F5`).
   - Акцентный цвет (для 1 слова): фирменный цвет бренда (например, `#FACC15` янтарный или `#38BDF8` лазурный).
   - Подложка/тень: тёмная полупрозрачная тень `drop-shadow(0 4px 12px rgba(0,0,0,0.65))` или плашка.
3. **Безопасные отступы:**
   - Шрифт субтитров должен масштабироваться так, чтобы самая длинная строка не превышала ширину **820 px** (при разрешении 1080x1920), оставляя по 130 px безопасности по бокам.
