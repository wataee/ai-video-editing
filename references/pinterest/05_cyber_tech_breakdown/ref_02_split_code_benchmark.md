# Референс: Split Code Benchmark (Сравнение архитектур)

- **Название приёма:** Разделенный экран со сравнением двух подходов в коде и таймером миллисекунд
- **Стиль:** `05_cyber_tech_breakdown`
- **Pinterest поиск:** `pinterest.com/search/pins/?q=tech%20code%20comparison%20motion`
- **Референс авторов:** The Primeagen, Fireship

---

## 1. Смысловой хук
- Наглядная демонстрация «Плохо vs Хорошо» или «Старый метод vs Новый AI-пайплайн».
- Слева подсвечивается красный блок `SLOW: 4200ms`, справа зеленый `FAST: 14ms`.

---

## 2. Параметры анимации (Remotion)
- Разделительная неоновая линия по центру экрана.
- Быстрый счетчик миллисекунд через компонент `<NumberTicker />`.
