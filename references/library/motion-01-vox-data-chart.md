# Моушн-референс #01: Vox Editorial Data Chart

- **Ссылка / Источник:** [Vox Video Explainer Motion System](https://www.vox.com/)
- **Ниша:** Моушн-дизайн / Аналитическая графика
- **Дата анализа:** 2026-10-16

---

## 1. Смысловая задача
- Превратить сухие статистические данные в наглядную драматическую кульминацию без использования шаблонных графиков.

---

## 2. Физика и кинематика движения
- **Появление:** Сетка графика проявляется через плавное нарастание прозрачности (fade-in, 0.3s).
- **Рост столбцов (Bars):** Столбцы растут снизу вверх с пружинным затуханием `spring({ damping: 14, stiffness: 120 })`. Рост занимает ровно 0.6 секунды.
- **Подписи:** Цифры над столбцами синхронно отсчитываются через `NumberTicker` от 0 до целевого значения.
- **Камера:** Легкий диагональный дрейф камеры (push-in 1.0 -> 1.04) на протяжении всего показа графика.

---

## 3. Звуковая хореография
- **Начало графика:** Мягкий воздушный свист перемещения (`whooshes/air_subtle.wav`, -20 dB).
- **Рост каждого столбца:** Короткий аналоговый щелчок (`textures/click_01.wav`, -16 dB).
- **Кульминация (финальный бар):** Акцентный звонкий поп или резонирующий колокольчик.

---

## 4. Что берем в Remotion / код
- Компонент `src/components/VoxBarChart.tsx`: реализация роста столбцов через Remotion `spring()`, отображение дельты роста (+89%), размещение строго внутри `<SafeZoneContainer>` без перекрытия лица спикера.
