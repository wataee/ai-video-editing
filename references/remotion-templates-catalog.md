# Каталог Remotion-шаблонов (RVE Templates Catalog)

> **Источник:** [reactvideoeditor/remotion-templates](https://github.com/reactvideoeditor/remotion-templates)  
> **Лицензия:** Free / MIT-compatible (бесплатное использование в любых проектах).  
> **Локальное расположение библиотеки:** `references/remotion-templates-rve/templates/`

Коллекция содержит **81 готовый компонент** для Remotion. Все шаблоны построены на нативных хуках (`useCurrentFrame`, `interpolate`, `spring`, `useVideoConfig`) и **не требуют сторонних тяжелых анимационных библиотек или CSS keyframes**.

## 3. Пример интеграции шаблона в проект Remotion

Чтобы интегрировать шаблон (например, `StatCounter`) в `remotion-blank-starter` или `remotion-tiktok-starter`:

1. Скопируйте `references/remotion-templates-rve/templates/stat-counter.tsx` в `src/components/StatCounter.tsx`.
2. В компоненте `src/Composition.tsx` вызовите его поверх основного видеоряда через `<Sequence>`:

```tsx
import { AbsoluteFill, Sequence } from "remotion";
import StatCounter from "./components/StatCounter";

export const MyComposition = () => {
  return (
    <AbsoluteFill style={{ backgroundColor: "#000000" }}>
      {/* Слой основного видео */}
      
      {/* Акцентная инфографика с 3-й по 6-ю секунду (кадры 90-180 при 30 fps) */}
      <Sequence from={90} durationInFrames={90}>
        <div style={{ position: "absolute", bottom: 400, width: "100%" }}>
          <StatCounter />
        </div>
      </Sequence>
    </AbsoluteFill>
  );
};
```
