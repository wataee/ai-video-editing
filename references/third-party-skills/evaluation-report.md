## 2. Детальный разбор: `davila7/claude-code-templates`

- **Что представляет собой навык:**  
  Коллекция промптов, обучающих Claude генерировать композиции Remotion на базе общих рекомендаций React.
- **Технические ограничения:**  
  - Содержит устаревшие рекомендации для ранних версий Remotion (3.x/ранние 4.x).
  - Не учитывает новые API `@remotion/captions` и оптимизированный рендеринг через OffthreadVideo.
  - Не содержит встроенных проверок на безопасные зоны TikTok/Reels.
- **Решение:**  
  Все ценные идеи (минимализм параметров, валидация Props через Zod) уже интегрированы в наш файл `style-guide.md` и официальные навыки `remotion-dev`.

## 3. Детальный разбор: Навык `Reel` (skills.sh)

- **Что предлагает навык:**  
  Автоматизацию создания «AI-рилсов под ключ»: подаётся тема ➔ генерируется текст ➔ через ElevenLabs синтезируется аудио ➔ через генератор картинок создаются фоны ➔ ролик собирается через FFmpeg.
- **Критические уязвимости и риски:**  
  1. *Утечка данных и затраты:* Требует передачи секретных API-ключей в окружение агента. Любой сбой в цикле генерации может привести к расходу платного баланса сторонних сервисов.
  2. *Несовместимость с ОС:* Скрипты автоматизации написаны под Bash (Unix pipe) и ломаются в Windows PowerShell.
  3. *Качество контента:* Генерирует шаблонные «бездушные» ролики со стоковыми картинками и роботизированным голосом, что прямо нарушает наши редакционные стандарты из `hooks.md` и `style-guide.md` (приоритет реального спикера и фактов).
- **Решение:**  
  Исключить из активных инструментов. Все пайплайны транскрибации и монтажа строятся локально (faster-whisper + Remotion + FFmpeg) без платных облачных подписок.

## 4. Итоговая архитектура навыков в системе

В рабочей директории `%USERPROFILE%\Videos\AI-Video-Editing\.agents\skills\` развернуты **12 официальных навыков Remotion**:
1. `remotion-best-practices` — генеральный свод правил разработки.
2. `remotion-captions` — точная работа с субтитрами и пословными таймкодами.
3. `remotion-create` — создание новых композиций и проектов.
4. `remotion-docs` — поиск по актуальной документации Remotion API.
5. `remotion-interactivity` — интерактивные контролы в Remotion Studio.
6. `remotion-maps` — визуализация карт и маршрутов.
7. `remotion-markup` — вёрстка текста, слоёв и таймингов в React.
8. `remotion-multimedia` — обработка аудио/видео метаданных через Mediabunny.
9. `remotion-render` — регламент пострендерного экспорта и стоп-кадров.
10. `remotion-saas` — архитектура интеграций и серверного рендера.
11. `remotion-studio` — управление локальным веб-просмотром.
12. `remotion-upgrade` — безопасное обновление зависимостей.
