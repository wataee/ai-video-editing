2. **Approval Gate в `render:clip` (Пункт 3):**
   - Скрипт `render:clip` в `package.json` защищен предварительным вызовом `node tools/check_approval.mjs`.
   - В `check_approval.mjs` реализована гибкая поддержка позиционного аргумента (`.json` или директория с `edit_plan.json`), что обеспечивает прозрачную работу вызова `npm run render:clip -- <путь>`.
   - Добавлен набор быстрых тестов `tests/test_approval_gate.py` (3 теста: `approved=false`, `approved=true`, несуществующий файл).

3. **Быстрые тесты, линтер комментариев и оптимизация CI (Пункт 4):**
   - Добавлены модульные тесты без использования браузера Chromium:
     - `tests/test_render_clip_helpers.py`: разрешение путей (`resolve_file_path`), валидация параметров выходного MP4 по ffprobe (`verify_output_mp4`), проверка наличия аудиодорожки (`check_voice_has_audio`).
     - `tests/test_calculate_metadata.py`: математика длительности и дефолтные параметры композиции Remotion.
   - Разделен CI workflow (`.github/workflows/ci.yml`):
     - На каждый `push` и `pull_request`: установка зависимостей (`npm ci`), `npm run typecheck`, проверка отсутствия комментариев (`python tools/check_no_comments.py`), компиляция `tools/*.py` и быстрые тесты `pytest tests/ -m "not slow"`.
     - Тяжелый E2E-тест вынесен в отдельный job с запуском по расписанию раз в неделю и вручную (`workflow_dispatch`) с предварительным выполнением `npx remotion browser ensure`.
   - Разработан инструмент `tools/check_no_comments.py` для контроля жесткого правила `CLAUDE.md` (полный запрет комментариев в коде), очищены компоненты `assets/motion/`.

4. **Отказоустойчивость и безопасность `tools/render_clip.py` (Пункт 5):**
   - Устранен скрытый автоподбор случайных видеофайлов из `work/ingest`: при отсутствии файла в плане выводится предупреждение с путем кандидата и требуется явный флаг `--allow-source-guess`, иначе выполнение прерывается с exit code 1.
   - Рендер без исходного видео разрешен только при явной передаче флага `--no-source`.
   - Перед рендером через `ffprobe` валидируется наличие аудиодорожки у `voice_source` (при отсутствии — понятная ошибка).
   - Добавлен параметр `--concurrency` (по умолчанию 2) для защиты от исчерпания памяти и ошибки видеокомпозитора Remotion (`No frame found at position`).
   - В `README.md` добавлен раздел «Troubleshooting» с инструкциями по загрузке Chromium, установке FFmpeg/FFprobe и настройке `npx`.
