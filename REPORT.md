### Блок C. Рендер на реальном видео (главный блок)
1. **Надежная передача видео в Remotion (`ReelFromPlan.tsx`):**
   - Удалена жестко закодированная регулярка под Windows-пути (`C:\...AI-Video-Editing`).
   - `render_clip.py` формирует изолированную структуру временной public-папки, связывая каталог `assets/` и исходный видеоролик, и передает флаг `--public-dir` в Remotion.
   - Поддерживаются относительные пути клиентов (`clients/<имя>/work/ingest/...`).
2. **Динамические метаданные (`calculateMetadata`):**
   - В композицию `ReelFromPlan` добавлена функция `calculateMetadata`. Длительность `durationInFrames` рассчитывается по формуле `Math.round(plan.target_duration_sec * fps)`. Размеры и fps извлекаются из плана (по умолчанию 1080×1920 @ 30 fps).
3. **Отказоустойчивый и кросс-платформенный `render_clip.py`:**
   - Убран вызов `cmd.exe /c`. Поиск бинарника `npx` выполняется через `shutil.which` (`npx.cmd` на Windows, `npx` на Linux/Mac).
   - Вывод ошибок FFmpeg направлен в `stderr` без глушения.
   - При сбое генерации аудиомикса скрипт прерывает работу с кодом 1, а не подменяет звук молча. Для явного разрешения фоллбэка добавлен аргумент `--allow-voice-fallback`.
   - Добавлена обязательная автоматическая верификация через `ffprobe`: наличие видеопотока, аудиопотока и проверка хронометража ролика с точностью до ±0.5 с.
   - В `SfxAudio.tsx` добавлена нормализация расширений (`.wav`) и игнорирование плейсхолдеров `'TODO'`.
4. **Сквозной интеграционный тест (`tests/test_e2e.py`):**
   - Полный сквозной тест: генерация 10-секундного ролика (FFmpeg testsrc + sine) -> `tools/ingest.py` -> `tools/plan_scaffold.py` -> установка `approved: true` -> сборка в `tools/render_clip.py` -> валидация контейнера через `ffprobe` (1080×1920, 30 fps, аудиопоток, длительность 10.0с ± 0.2с). Тест помечен как `@pytest.mark.slow`.
